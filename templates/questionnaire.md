# 📋 全场景家庭亲子旅行前置问卷 (Universal Pre-flight Questionnaire)

在为家庭定制旅行规划前，主动向用户收集以下 **4 大核心维度信息**：

```markdown
### 1. 👥 出行人员与年龄画像 (Travelers & Age Cohorts)
- **出行总人数**：[几大几小？如：三口之家 / 三代同堂 4-6 人]
- **儿童年龄与成长特征**：
  - [ ] **0-2 岁 幼童期**：需推车全程保障、强制 14:00-16:00 大床午睡、纯软烂无刺饮食、换尿布与温奶。
  - [ ] **3-6 岁 中童期 (如 5 岁)**：精力充沛、爱美当小公主/小英雄、喜欢动手非遗体验（木偶/簪花/手工）、沙滩挖沙、自选小吃。
  - [ ] **7-12 岁 大童期**：科普研学、中高刺激游乐项目、自主探索。
  - *儿童精确身高*：[如 92cm / 115cm，用于匹配乐园身高阈值]
- **长辈特征 (若有)**：[年龄，体力走动耐受度，膝盖状况，清淡热汤饮食偏好]
- **父母分工与诉求**：[主驾/摄影/带娃，是否需要单人通道单刷大项目]

### 2. 🚆 交通出行方式决策 (Transportation Mode)
- **出发地与目的地**：[如：杭州东 ➔ 泉州 / 杭州 ➔ 上海迪士尼 / 杭州 ➔ 三亚]
- **出行模式选择**：
  - [ ] **🚄 高铁慢游直达**：适合 3-5 小时直达城市，零驾驶疲劳，市内全打车 + 步行无缝衔接。
  - [ ] **⚡ 纯电动车自驾 (EV)**：核算真实续航，沿途商场地库极充 18-30 分钟 + 吃饭免停车费。
  - [ ] **⛽ 燃油车自驾**：出发前加满一箱油（极简处理），专注避开早晚高峰限行。
  - [ ] **✈️ 飞机落地租车/包车**：海岛/跨省度假，落地租 7 座商务车或 SUV（带安全座椅）。

### 3. 🗓️ 时间、住宿大本营与核心主题 (Dates & Theme)
- **行程天数与具体日期**：[如：3天2晚，周五出发周日返程]
- **住宿大本营偏好**：[如：核心古城红砖古厝客栈 / 一线海景亲子度假酒店 / 乐园官方周边酒店]
- **核心游玩偏好**：[历史非遗体验 / 老饕美食巡礼 / 乐园沉浸 / 海滩挖沙 / 自然吸氧]
```
